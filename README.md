# 사주 살펴보기

생년월일과 출생시간으로 사주 네 기둥을 계산하고, 전통 명리학의 기초 상징을 읽어 보는 로컬 웹 프로그램입니다. 한국 음력과 절입을 적용하며, 저장한 사주 목록은 현재 브라우저에 보관합니다. 마지막 풀이 결과는 서버를 다시 시작하면 초기화됩니다.

이 프로그램은 전통 명리의 상징을 바탕으로 사주를 살펴보는 참고 자료입니다. 성격이나 미래를 과학적으로 예측하는 도구는 아니므로 가볍게 살펴봐 주세요.

현재 릴리스: **v0.7.3**. Windows 실행 파일 하나에서 프로그램을 시작하며, 소스·의존성·문서·설정은 `프로그램/` 폴더에 모았습니다. 별도 출생 입력 사이드바를 없애고 목록에서 불러온 사주를 전체 폭 본문에 표시합니다. 궁합은 저장 목록의 두 사람만 사용합니다. 전체 풀이 접기와 개별 풀이 접기의 제목·상태 표시를 통일해 접을 범위를 알아보기 쉽도록 했습니다. 이전 버전: v0.7.2(전체 접기·하위 항목 형식 통일), v0.7.1(Windows Node.js LTS 설치 동의·숨김 서버 실행·10초 탭 종료), v0.7.0(심화 풀이·궁합·신년운세·오늘의 운세·용어 풀이·인쇄), v0.6.9(출생 범위 1890~2050년, 역사적 표준시 반영), v0.6.8(Windows 실행 파일의 Node.js 설치 안내와 자동 의존성 설치), v0.6.7(현재 대운 천간·지지 판정이 엇갈릴 때 각각 안내), v0.6.6(상단 책 소개 링크), v0.6.5(부분 명식 판정 보류, 성격·직업·재물 확인 범위, 현재 대운·올해 세운 요약), v0.6.4(총평 문장 종결 수정), v0.6.3(총평과 성격의 지장간·관성 문장), v0.6.2(합화 규칙, 지장간 십성 표현, 대운·세운·월운 판정 문장, 경계 사례 안내).

## 시작하기

Node.js와 npm이 필요합니다. Git으로 저장소를 내려받아 폴더에 들어갑니다. GitHub 릴리스에서 소스 ZIP을 내려받아 압축을 풀어도 됩니다.

```sh
git clone https://github.com/iamtalker/saju.git
cd saju
cd 프로그램
```

최초 실행 전에 의존성을 설치하고 서버를 시작합니다.

```sh
npm install
node server.js
```

브라우저에서 [http://127.0.0.1:3210](http://127.0.0.1:3210)을 엽니다. Windows에서는 저장소 루트의 `실행하기.cmd`를 더블클릭하면 됩니다. Node.js가 없으면 설치 여부를 먼저 묻고, 동의하면 공식 Node.js 사이트에서 LTS 설치 파일을 내려받습니다. 의존성이 없으면 `프로그램/node_modules`에 설치합니다. 서버는 숨겨서 실행되며 마지막 브라우저 탭을 닫으면 10초 뒤 종료됩니다. 자세한 내용은 [사용방법](프로그램/사용방법.md)을 참고하세요.

## 주요 기능

- 양력·한국 음력·윤달 입력, 출생시간 미상 선택
- 연주·월주·일주·시주와 천간·지지, 오행·십성·지장간 표시
- 일간 상징, 기둥별 풀이 안내, 표면 오행 분포, 월지·지장간 십성, 십이운성, 천간합·육합·충·삼합·방합 표시
- 신강·신약(득령·득지·득세 충족 개수로 판정), 격국, 조후, 용신·희신·기신·한신 판정과 판정 기준 공개
- 세운·대운·월운의 천간과 지지를 용신·희신·기신으로 판정하고 원국과의 합·충·형·파·해 관계 표시, 월운은 점수 합계로 좋은 달·보통·주의 구분
- 성격·직업·재물 풀이: 월지 본기, 천간에 드러난 십성, 지장간 위치를 근거로 각 항목의 요약과 상세 풀이를 화면과 Markdown에 함께 표시
- 월주가 확정되지 않은 부분 명식: 확정된 기둥으로 기초 풀이를 보여 주고, 월주가 필요한 판정은 보류 사유와 함께 보류
- 결과 상단의 풀이 목차에서 해당 설명으로 이동, Markdown 파일로 풀이 내보내기
- 도화살·역마살·화개살·천의성의 기준 지지와 발견 위치 표시
- 앞으로 12년의 세운 지지와 원국 지지 충 관계 및 해당 연도 만 나이 범위 표시
- 출생연도 간지와 선택한 성별 기준으로 순행·역행을 정하고 대운 8개와 근사 시작 시점 표시. 성별을 고르지 않으면 연주·월주가 확정된 경우 남성·여성 두 기준을 함께 표시
- 페이지 상단의 사주 목록에서 생년월일과 이름을 입력해 저장, 다시 불러오기·이름 변경·삭제
- 서버를 다시 시작하면 마지막 계산 결과를 초기화(저장한 사주 목록은 유지)
- 출생시간 보정값과 밤 11시/자정 일주 변경 기준 선택
- 1987~1988년 서머타임 및 시간 미상·절입일 불확실성 안내
- 저장한 사주 목록을 현재 브라우저의 로컬 저장소에 보관
- 심화 풀이: 60갑자 일주론 표, 일지 본기 십성 중심의 배우자 자리, 연·월·시주의 가족 자리, 오행 균형과 장부·계절 생활 관리, 8개 대운의 십성·판정 흐름, 용신 기반 개운 조언(전통 상징과 경향 설명)
- 궁합 보기: 사주 목록에 저장한 두 사람을 골라 일간·일지·띠 관계, 오행 보완, 용신 보완, 소통 방식 차이를 참고 풀이로 보여 줍니다. 좋고 나쁨을 판정하지 않으며 Markdown으로 저장할 수 있습니다.
- 노란 안내 줄에서 전체 풀이를 한 번에 접거나 펼치기, 각 풀이 카드와 하위 항목의 접기 상태를 같은 형식으로 표시
- 재미 풀이 모음(성격·재물·연애·연봉 지수·올해 좋은 달 등). 근거가 없으며 재미로만 봅니다.
- 한눈에 보기: 일간 상징, 신강·신약, 격국, 용신, 두드러진 오행을 칩과 세 문장으로 요약
- 오늘의 운세: 오늘 일진의 십성, 일지와의 합·충, 용신 오행과의 대조, 생활 팁 한 가지
- 신년운세: 다음 해 세운의 십성과 판정, 올해 남은 기간의 월운, 다음 해 12달의 월별 간지 풀이(좋은 달·보통·주의 분류 재사용)
- 어울리는 직업군 예시: 월지 본기 십성, 원국에서 우세한 십성, 용신 오행에서 6~10개 예시(직업을 정하는 근거가 아님)
- 용어 풀이: 십성 10개, 용신·희신·기신·한신, 격국, 조후, 대운·세운·월운, 지장간, 십이운성, 합·충·형·파·해, 공망, 일주·일간·일지 설명과 본문 용어의 툴팁
- 인쇄·PDF로 저장: 접힌 항목을 모두 펼치고, 사주 목록과 궁합 패널을 뺀 인쇄용 화면을 엽니다
- 띠, 공망, 십신 개수, 올해 월별 간지, 오늘의 일진 계산 항목(해석 없음)
- 출생지 경도를 입력하면 진태양시와 균시차를 참고값으로 표시
- 대운 카드에서 다수 기준(년 반올림)과 개월 잔여 기준의 시작 나이를 나란히 표시

## 계산 기준과 한계

- 한국 출생 양력 기준 1890~2050년을 지원합니다. 음력 변환의 실제 경계는 라이브러리의 지원 범위(양력 1890-01-21~2050-12-31, 음력 1890-01-01~2050-11-18)를 따릅니다. 1962년 이전의 역사적 시간대·서머타임은 별도 검증되지 않았으므로 시각 경계 부근 결과는 주의가 필요합니다.
- 연주와 월주는 절입 시각을 기준으로 하며, 일주와 시주는 당시 표준시에서 입력한 보정 분을 뺀 시각으로 계산합니다. 기본 30분은 근사값이며 출생지와 균시차를 자동 계산하지 않습니다.
- 한국 음력은 `kor-lunar`, 절기는 `lunar-javascript`를 사용합니다. `@fullstackfamily/manseryeok`은 개발용 대조 스크립트에서만 사용하며 앱 계산에는 포함하지 않습니다. 절입의 초 단위 정확도와 전 기간 전체는 공식 역서와 검증하지 않았습니다.
- 합화는 원국 월지 본기 오행이 합화 오행과 같을 때만 성립합니다. 아니면 "묶입니다"로만 씁니다. 일간과의 합은 끌림으로만 표시하고 유불리를 붙이지 않습니다.
- 조후 용신이 화인 명식에서는 습토인 丑·辰을 희신으로 치지 않습니다. 대운·세운·월운의 지지가 원국 지지와 방합·삼합을 완성하면 그 합의 오행으로 평가합니다.
- 23시 일주 변경 및 시두법은 선택 가능한 관례 중 하나입니다. 다른 만세력과 비교할 때 시간 보정과 자시 처리 기준을 맞춰야 합니다.
- 시간 미상으로 확정할 수 없는 기둥은 표시하지 않습니다. 일주가 확정되지 않으면 임시 일간을 쓰지 않으며, 십성·신강약·격국·용신·공망·십신 개수·풀이 판정을 계산하지 않습니다. 서머타임 전환으로 존재하지 않거나 중복된 출생 시각은 입력을 거부합니다.
- 절입 전후 하루 안에 태어나면 절입 시각 기준으로 계산했다는 경고를 표시하고, 시각 기준으로 날짜를 맞춰 판정합니다.
- 풀이는 일간·표면 오행·월지·십성·십이운성·신살 표식의 기초 설명에, 신강·신약, 격국, 조후, 용신 판정과 세운·대운·월운의 관계 판정을 더한 것입니다. 신살은 도화·역마·화개는 년지·일지 삼합 기준, 천의성은 월지에서 한 칸 앞선 현대 표 기준을 사용하며 기준 차이가 있을 수 있습니다. 세운은 앞으로 12년의 연지와 원국 지지 충을 표시하고, 세운·대운·월운의 천간과 지지를 용신·희신·기신으로 판정합니다. 월운 점수는 천간과 지지의 가중치 합계이며, 원국 지지와의 충이 있으면 감점합니다. 대운은 양년 남성·음년 여성 순행, 음년 남성·양년 여성 역행 기준이며, 인접 절까지 일수를 3으로 나눈 값을 년 단위로 반올림합니다(최소 1년). 근사 계산입니다. 출생시간이 없으면 생략하고, 성별을 고르지 않으면 두 기준을 함께 보여 줍니다. 신살·충·대운 간지로 사고·질병·이별 등 실제 사건을 예측하지 않습니다. 신강·신약은 점수가 아니라 조건 충족 개수로 정하며, 격국·용신은 억부와 조후를 단순하게 적용한 결과이고 학파에 따라 다를 수 있습니다. 지장간 가중치·사령과 대운·세운·월운을 종합한 길흉 해석은 제공하지 않습니다. 십이운성은 화토동궁·양간 순행·음간 역행 기준입니다. 삼합·방합은 완성 여부만 표시하며 합화나 길흉을 판정하지 않습니다.
- 저장한 사주 목록은 브라우저 로컬 저장소에 저장하며 서버에 별도로 저장하지 않습니다. 같은 브라우저에서만 복원되고 사이트 데이터를 삭제하면 함께 사라집니다. 마지막 계산 결과는 서버를 다시 시작할 때 지워집니다. 글꼴을 불러올 때는 Google Fonts에 접속합니다.

### 다른 만세력과 비교하기

양력·음력 및 윤달 여부, 출생시간, 시간 보정, 자시의 일주 변경 기준을 동일하게 설정하세요. 예를 들어 다른 만세력에서 출생시각보다 37분 늦춰 계산한다면 출생시간 보정에 `37`을 입력합니다. 보정 없이 비교하려면 `0`을 입력하세요. 보정에 음수를 입력하면 그만큼 시간이 더해집니다.

계산 결과의 네 기둥은 화면 왼쪽부터 시주·일주·월주·연주 순서로 표시합니다. 절입일이나 자시 근처에는 선택한 기준이나 절입 자료의 차이 때문에 결과가 달라질 수 있습니다.

### 입력값 삭제

저장한 사주 목록은 현재 브라우저의 `http://127.0.0.1:3210` 사이트 데이터에 저장됩니다. 지우려면 해당 주소의 사이트 데이터를 삭제하세요. 마지막 결과는 서버를 다시 시작할 때 초기화됩니다. 개인 정보 보호 모드에서는 창을 닫으면 저장 목록이 사라질 수 있습니다.

| `프로그램/compat-reading.js` | 궁합 풀이: 일간·일지·띠 관계, 오행·용신 보완, 소통 방식, 종합 |
| `프로그램/extra-reading.js` | 한눈에 보기, 오늘·신년 운세, 직업군 예시, 용어 풀이와 툴팁 |
| `프로그램/index.html`, `프로그램/app.js`, `프로그램/style.css` | 사주 목록, 본문, 궁합 화면 |
| `프로그램/docs/`, `프로그램/검증/` | 조사 문서, 역법 대조 자료와 검증 스크립트 |
| `프로그램/실행하기_숨김.vbs`, `프로그램/설치_Node.js.ps1` | 서버 숨김 실행, Node.js LTS 자동 설치 보조 파일 |

서버는 기본적으로 `127.0.0.1:3210`에서만 수신합니다. 포트를 바꾸려면 서버 실행 전에 `SAJU_PORT` 환경 변수를 설정하고 해당 포트로 접속하세요. Windows 실행 파일은 기본 포트 3210을 엽니다.

## 개발과 릴리스 방식

- 작업, 커밋, 릴리스는 모두 `main` 브랜치에서 합니다. 별도 작업 브랜치는 만들지 않습니다.
- 릴리스할 때 `프로그램/package.json` 버전과 루트 README의 '현재 릴리스'·'최근 릴리스'를 갱신하고, 위 검증 스크립트를 모두 통과시킨 뒤 `main`에서 `vX.Y.Z` 태그와 GitHub 릴리스를 만듭니다.
