# 사주 살펴보기

생년월일과 출생시간으로 사주 네 기둥을 계산하고, 전통 명리학의 기초 상징을 읽어 보는 로컬 웹 프로그램입니다. 한국 음력과 절입을 적용하며, 입력한 정보는 브라우저에 기억합니다.

사주는 전통적 해석 체계이며 성격이나 미래에 대한 예측력이 과학적으로 입증된 것은 아닙니다. 결과는 참고용입니다.

## 시작하기

Node.js와 npm이 필요합니다. 저장소를 내려받은 뒤 폴더에서 다음 명령을 실행하세요.

```sh
npm install
node server.js
```

브라우저에서 [http://127.0.0.1:3210](http://127.0.0.1:3210)을 엽니다. Windows에서는 의존성 설치 후 `실행하기.cmd`를 더블클릭해도 됩니다. 종료하려면 서버 창에서 Ctrl+C를 누르거나 창을 닫으세요. 자세한 내용은 [사용방법](사용방법.md)을 참고하세요.

## 주요 기능

- 양력·한국 음력·윤달 입력, 출생시간 미상 선택
- 연주·월주·일주·시주와 천간·지지, 오행·십성·지장간 표시
- 일간 상징, 표면 오행 분포, 천간 십성, 기본 합·충 풀이
- 출생시간 보정값과 밤 11시/자정 일주 변경 기준 선택
- 1987~1988년 서머타임 및 시간 미상·절입일 불확실성 안내
- 입력값을 현재 브라우저의 로컬 저장소에 보관

## 계산 기준과 한계

- 한국 출생 양력 기준 1962~2050년을 지원합니다. 음력 변환의 실제 경계는 라이브러리의 지원 범위를 따릅니다.
- 연주와 월주는 절입 시각을 기준으로 하며, 일주와 시주는 당시 표준시에서 입력한 보정 분을 뺀 시각으로 계산합니다. 기본 30분은 근사값이며 출생지와 균시차를 자동 계산하지 않습니다.
- 한국 음력은 `kor-lunar`, 절기는 `lunar-javascript`를 사용합니다. 절입의 초 단위 정확도와 전 기간 전체는 공식 역서와 검증하지 않았습니다.
- 23시 일주 변경 및 시두법은 선택 가능한 관례 중 하나입니다. 다른 만세력과 비교할 때 시간 보정과 자시 처리 기준을 맞춰야 합니다.
- 시간 미상으로 확정할 수 없는 기둥은 표시하지 않습니다. 서머타임 전환으로 존재하지 않거나 중복된 출생 시각은 입력을 거부합니다.
- 풀이는 일간·표면 오행·천간 십성의 기초 상징입니다. 신강·신약, 격국·용신, 대운 및 종합적인 운세 예측은 구현하지 않았습니다.
- 브라우저 로컬 저장소에 입력값을 저장하며 서버에 별도로 저장하지 않습니다. 같은 브라우저에서만 복원되고 사이트 데이터를 삭제하면 사라집니다. 글꼴을 불러올 때는 Google Fonts에 접속합니다.

## 검증

```sh
node 검증/프로그램_검증.js
node 검증/한국음력_후보_검증.js
node 검증/2024년_한국음력_대조.js
node 검증/2025년_한국음력_대조.js
node 검증/십성_100조합_대조.js
node 검증/십이운성_120조합_대조.js
```

음양력의 공개 달력자료 표본 대조와 내부 왕복 검사, 십성·십이운성의 구현 간 대조입니다. 전체 범위의 정확성이나 풀이의 예측력을 보증하지 않습니다. `검증/2023년_역법_대조.js`는 중국력과 한국력의 차이를 보여주는 조사 스크립트로, 알려진 차이를 발견하면 종료 코드 1을 반환합니다.
