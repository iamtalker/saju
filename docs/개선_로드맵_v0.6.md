# 개선 로드맵 v0.6

작성일 2026-11-16. 외부 피드백 네 건을 검토해 받아들일 항목과 받아들이지 않을 항목을 정했다. 기준은 [계산 기준 선언](계산_기준_선언.md)과 같다.

## 받아들인 항목 (구현)

| 번호 | 항목 | 이유 |
|---|---|---|
| A | 세운과 원국의 지지 관계 확장: 육합·형을 충과 함께 식별 | 관계 식별은 계산 항목이다. 충만 보는 것은 거칠다는 지적이 맞다. |
| A2 | 세운 천간과 원국 천간의 천간합 식별 | 같은 이유 |
| B | 대운을 표로 표시하고 원국과의 충 관계를 열로 표시 | 대운 데이터는 이미 계산되어 있다. 목록보다 표가 읽기 쉽다. |
| C | 성별이 없으면 남성 기준과 여성 기준 두 방향을 모두 표시 | 두 방향은 성별에 따라 정확히 뒤바뀐다. 두 결과를 보여 주면 사용자가 선택할 수 있다. |
| D | 십성 개수를 텍스트 막대로 표시 | 기존 개수를 보여 주는 방식만 바뀐다. 가중치는 쓰지 않는다. |
| E | 월지 계절 설명 한 줄 추가 | 寅卯辰 봄, 巳午未 여름, 申酉戌 가을, 亥子丑 겨울은 명리 일반론이다. 강약 판정은 하지 않는다. |
| F | 재미 풀이에서 신강·격국·용신 카드 삭제 | 맨 위 안내의 "전문 간명은 포함하지 않음"과 모순된다는 지적이 맞다. |
| G | 재미 풀이에 일간 한 줄을 결론 한 줄로 묶어 표시 | 사용자가 결론 한 줄을 원한다는 점을 받아들인다. 단, 재미 풀이로만 표시한다. |

## 받아들이지 않은 항목

| 항목 | 이유 |
|---|---|
| 신강 23점·신약 77점 같은 점수 | 가중치 규칙의 근거가 없다. 점수로 보이면 정밀해 보여서 오해를 키운다. |
| 오행 가중치 점수 (목 12, 화 3 등) | 지장간 비중의 근거가 없다. |
| 직업·취미 AI 추론 | API 키와 근거가 없다. |
| 지장간 辛 하나 주장으로의 전면 교체 | 표준이 하나로 정해져 있지 않다. 현재 표는 여기와 정기를 함께 보는 공개 구현 세 곳과 같다. 십성 개수는 이미 정기 기준이다. |

## 그 밖에 확인된 사항

- 월주 경자는 맞다. 1982년 소한은 1월 6일 00:02(베이징 시간)이다.
- 천을귀인은 재미 풀이의 "귀인(관례)" 항목에 이미 있다.
- 공망 午未도 맞다.

## 구현 상태 (2026-11-16)

- A·A2: 세운·대운과 원국의 천간합, 지지 육합·형을 식별해 세운 카드에 표시한다. 충은 기존대로 표시한다.
- B: 대운을 표로 표시한다. 열은 순서, 간지, 나이, 시작 시점, 원국과의 충 관계다.
- C: 성별이 없으면 남성 기준과 여성 기준의 대운을 모두 표시한다.
- D: 십성 개수를 막대(█)로 표시한다.
- E: 월지 카드에 계절 한 문장을 추가했다.
- F: 재미 요약에서 신강·신약, 격국, 용신 카드를 뺐다.
- G: 재미 요약에 결론 한 줄을 추가했다.
- 문구: 재미·농담·흥미 표현을 풀이 문장에서 뺐다. 맨 위 안내 한 줄만 남겼다.

검증 스크립트는 모두 통과했다(2023년 역법 대조의 종료 코드 1은 알려진 차이 표시). 브라우저 화면은 이번에 확인하지 못했다. 실행 중인 서버가 이전 엔진을 들고 있어서 재시작 후 확인해야 한다.
