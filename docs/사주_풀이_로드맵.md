# 사주 풀이 확장 로드맵

갱신일: 2026-11-16. 해석 기능은 전통 분류를 설명하는 참고 도구이며 성격이나 사건을 검증된 사실처럼 예측하지 않는다.

## 완료

### 사용 흐름과 결과 보관

- 검색 성공 시 이름과 입력값을 브라우저 저장 목록에 추가한다. 같은 조건을 다시 검색하면 기존 항목을 갱신한다.
- 목록에서 다시 계산하고 이름을 변경하거나 항목을 삭제할 수 있다.
- 마지막 결과와 입력값을 함께 저장해 새로고침 뒤 복원한다.
- 결과 상단 목차에서 각 설명으로 이동하고, 같은 내용을 Markdown 파일로 내려받는다.
- 저장 데이터는 브라우저 로컬 저장소에만 둔다.

### 1. 기둥별 안내와 십이운성

- 연주·월주·일주·시주의 기본 역할을 결과에 함께 표시한다.
- 일간을 기준으로 네 지지의 십이운성을 표시한다. 일간이 미상이면 산출하지 않는다.
- 화토동궁, 양간 순행·음간 역행 기준을 밝힌다. 이는 선택한 한 방식이며 모든 학파의 합의를 뜻하지 않는다.

### 2. 지지 삼합·방합 후보

- 삼합·방합에서 발견한 글자, 자리, 관련 오행을 표시한다.
- 세 글자가 모두 갖춰졌는지와 빠진 글자가 있는 부분 후보인지를 구분한다.
- 부분 조합은 작용이나 성립을 확정하지 않는다. 합화와 길흉도 판단하지 않는다.

### 3. 지장간과 월지

- 월지와 그 지장간의 십성을 표시한다.
- 기둥별 지장간 십성 풀이를 별도 구획으로 제공한다.
- 지장간의 배열을 사용하며 사령·가중치·강약은 계산하지 않는다.

### 서버 종료

- 서버는 Ctrl+C, 표준입력 종료 또는 이를 띄운 셸 종료를 감지해 종료한다.
- 셸 종료 감시는 부모 프로세스가 사라졌는지 확인하는 방식이며, 서버 창을 닫은 뒤 포트 3210이 닫히는 통합 점검을 수행한다.

### 신살 표식과 세운 관계

- 도화·역마·화개·천의성의 적용 기준과 발견 위치를 표시한다.
- 앞으로 12년의 세운 지지와 원국 충 관계, 해당 연도의 만 나이 범위를 표시한다.
- 기준별 차이와 예측 한계를 [신살·세운 구현 기준](신살과_세운_구현기준.md)에 기록한다.

### 대운 간지와 기산 시점

- 대운 순역행에 사용할 성별을 선택 입력으로 받고 로컬에 보관한다.
- 년간 음양·성별로 방향을 정하고, 인접 절입까지의 시각 차이를 3일=1년으로 환산한다.
- 월주에서 진행하는 8개 대운 간지와 근사 시작일·교체일을 표시하고 Markdown 내보내기에 포함한다.
- 선택한 규칙과 학파별 차이는 [신살·세운 구현 기준](신살과_세운_구현기준.md)에 기록한다.

## 다음 단계

### 4. 역법 검증 확대

- 공식 발표 월력요항·역서와 여러 해의 절입 및 경계 사례를 대조한다.
- 입춘·절입일, 자시, 보정 후 날짜 변경, 역사적 표준시를 별도 표본으로 기록한다.
- 지원 범위를 넓히기 전에 범위별 검증 자료와 한계를 함께 공개한다.

### 5. 대운 계산 검증과 비교 화면

- 경계 출생시각, 서머타임, 절입 직전·직후 표본으로 시작 시점과 대운 간지를 대조한다.
- 남녀·양년/음년 순역행 조합과 60갑자 월주 순환을 회귀 검증한다.
- 성별 및 계산 기준에 따라 결과가 달라질 수 있음을 설명하고, 기준별 결과 비교를 제공한다.
- 대표성 있는 근거 없이 하나의 기준을 보편 관례라고 단정하지 않는다.

### 6. 신강·신약, 격국, 용신의 선택형 모듈

- 고전·국내 교재 본문과 재현 가능한 사례를 확보하고, 규칙과 예외를 문서화한다.
- 이론별 결과를 분리해 설명하며 서로 다른 기준을 한 점수나 단일 정답으로 합치지 않는다.
- 근거와 충돌 처리가 마련되기 전에는 자동 판정을 추가하지 않는다.

## 현재 기능 검증 시 주의

- 관계 목록은 조합의 존재를 식별한다. 합화·작용력·현실 사건을 증명하지 않는다.
- 120개 십이운성 조합의 기존 대조는 선택한 계산 방식과 `lunar-javascript`의 구현 간 비교다. 독립적인 문헌 합의 검증은 아니다.
- 한국 음력 및 절입 검증은 표본 중심이다. 전체 연도와 모든 경계의 정확성을 보증하지 않는다.
