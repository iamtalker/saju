# 외부 피드백 검토와 로드맵 v0.7

작성일 2026-11-16. 페이블 모드 피드백을 항목별로 검산했다.

## 검산 결과

| 피드백 | 판정 | 처리 |
|---|---|---|
| 세운 충 누락 (2026 午子, 2035 卯酉, 2037 巳亥) | 맞음. 세운 간지가 빠지던 버그 | 수정 완료, 회귀 테스트 추가. 2038은 12년 범위 밖이라 해당 없음 |
| 조사 처리 깨짐 (수이, 무을, 일지 자 원국 등) | 맞음 | 받침 판별 조사 함수를 추가해 해당 자리 수정 |
| 보정 23:00 → 22:31 (29분) | 현재 코드에서는 틀림. 22:30으로 나옴. 22:31은 이전에 저장된 예시 파일의 값 | 조치 없음 |
| 재물 항목이 지지를 빼먹음 | 맞음 | 천간과 지지 본기를 함께 표시하도록 수정 |
| 관성 "아예 없다"는 과장 | 맞음 | "천간에 관성이 보이지 않아"로 수정 |
| 서머타임 1948~51, 1955~60 누락 | 범위 밖. 앱은 1962년 이후만 지원 | 조치 없음 |
| 문장 깨짐과 중복 | 일부 맞음. 깨진 문장은 수정. 중복 카드는 다음 단계 | 문장 수정 완료 |
| 연봉 지수 95점이 명리 논리와 반대 | 맞음. 근거 없는 임의 점수 | 카드 삭제 |
| 신강·신약, 종격, 조후, 용신 판정 | 방침 결정 필요. 사주정설의 강약·용신 규칙을 기준으로 할지 정하지 않음 | 보류 |
| 대운 누락 | 성별 입력 시 계산됨. 미입력 시 남녀 두 기준을 모두 표시 | 완료(이전 단계) |
| 형·파·해·원진 누락 | 맞음. 식별만 하는 방식으로 추가 가능 | 다음 단계 |
| 경계 사례 옵션 (자시, 절입 근처 대안 명식) | 맞음. 옵션과 대안 표시는 설계가 필요 | 다음 단계 |
| 종합 해석 단락 | 방침 결정 필요. 규칙 해석이면 방침과 충돌 | 보류 |

## 다음 단계

1. 형·파·해·원진 식별 추가 (계산 항목)
2. 경계 근처 출생에 대해 대안 명식 표시 (옵션 설계 후)
3. 신강·신약 및 용신 규칙: 기준 문헌 결정 후 적용 범위를 정함
4. 중복 카드 정리 (지장간 두 번 표시 등)

## 구현 상태 (추가)

- 신강·신약 충족 여부: 득령(월지 본기가 비겁·인성), 득지(일지 지장간에 비겁·인성), 득세(일간 제외 천간 3개와 지지 본기 4개 중 비겁·인성 2개 이상)를 세고, 3개 신강, 0개 신약, 1~2개 갈림으로 표시한다. 점수는 쓰지 않는다. 1982-01-05 명식은 신약, 1981-03-20 명식은 갈림으로 나온다.
- 경계 근처 출생: 자시 전후 60분 또는 절입 전후 60분이면 경고를 붙이고, 일주 경계를 바꾸었을 때와 보정 0분일 때의 명식이 다르면 대안을 함께 보여 준다. 1982-01-05 23:00(보정 30분)은 보정 0분일 때 시주가 임자로 바뀐다.
