# 신살·세운 표시 기준

작성일: 2026-11-16. 여기에 표시하는 항목은 전통 명리 안에서 쓰이는 분류이며, 성격·건강·직업·사건의 실증적 예측으로 취급하지 않는다.

## 원국 신살 표식

| 항목 | 기준 | 대상 지지 |
|---|---|---|
| 도화살 | 년지 또는 일지의 삼합 그룹 | 신자진→유, 인오술→묘, 사유축→오, 해묘미→자 |
| 역마살 | 년지 또는 일지의 삼합 그룹 | 신자진→인, 인오술→신, 사유축→해, 해묘미→사 |
| 화개살 | 년지 또는 일지의 삼합 그룹 | 신자진→진, 인오술→술, 사유축→축, 해묘미→미 |
| 천의성 | 월지에서 지지 순서 한 칸 앞 | 현대 자료에 나타나는 표를 참고. 고전 자료의 천의와 기준이 다를 수 있음 |

발견된 대상 지지가 어느 기둥에 있는지와 기준 지지를 함께 표시한다. 연지·일지 기준이 겹치는 위치는 한 번만 표시한다. 출생시간 미상은 시지를 검사하지 않는다. 신살의 수를 길흉 점수로 환산하지 않는다.

도화·역마·화개 삼합 대응표는 [타로또 신살 계산 안내](https://tarotto.vuedot.co.kr/manseryeok/sinsal/)의 기준 설명과 대조했다. 천의성은 현대 월지 표와 고전 자료가 다른 위치를 가리킬 수 있어 [천의성 기준 비교](https://tarotto.vuedot.co.kr/blog/saju-cheonuiseong-guide/)를 참고해 화면에 기준 설명을 붙였다. 해당 페이지는 상업 서비스의 설명 자료이므로 고전 원전 자체를 독립 검증한 근거로 보지 않는다.

## 세운 충 표시

현재 연도부터 12개 연도의 입춘 이후 연주를 구하고, 해당 연도의 지지가 원국의 연지·월지·일지·시지와 충을 이루는 경우를 나열한다. 화면의 나이는 해당 양력 연도의 생일 전후 만 나이 범위(연도−출생연도−1 ~ 연도−출생연도)다. 연주는 3월 1일 정오로 산출해 입춘 이후 값을 얻는다.

## 대운 첫 구현

순행은 양년 남성·음년 여성, 역행은 음년 남성·양년 여성 기준이다. 월주에서 60갑자를 한 칸씩 전진 또는 후진해 10년 단위 간지 8개를 만든다. 순행은 출생 순간에서 다음 절입까지, 역행은 직전 절입에서 출생 순간까지의 실제 시간 간격을 사용한다.

간격 3일을 1년으로 환산해 1일은 4개월로 처리하고, 시작 나이는 개월 단위로 반올림한다. 근사 대운 시작일은 반올림 전 시간 간격을 열대년(365.2425일) 비율로 환산해 출생 순간에 더한다. 이는 앱이 택한 구현 규칙이다. 대운수의 나머지 처리와 교운일은 자료마다 다르므로 모든 만세력의 기준이라고 주장하지 않는다. 출생시간 또는 성별 기준을 입력하지 않거나 연·월주를 확정하지 못하면 대운은 계산하지 않는다.

기본 순역행은 [대운 계산법 검토 논문 초록](https://www.riss.kr/search/detail/DetailView.do?control_no=b4be2ffb1edb604de9810257f7042666&p_mat_type=1a0202e37d52c72d)과 [공개 구현의 계산 명세](https://github.com/nanamix/korean-fortune-system/blob/master/docs/reference/03-saju-calculation-methodology.md)를 참고했다. 논문은 고전 원론 방식과 현대 절기 방식 및 프로그램 사이의 차이를 설명하므로, 이 구현을 하나의 관례로 한정한다. 인접 절입 시각은 현재 계산에 쓰는 `lunar-javascript`의 절입 계산을 사용한다.

세운 충 표시는 계속 대운과 독립된 참고 정보다. 충 표시는 전통적인 관계 이름이며 사고·질병·이별을 예보하지 않는다. 대운 간지와 시기 역시 길흉이나 특정 사건을 판정하지 않는다. 월운·일진은 다루지 않는다.

## 다음 확장 전 확인할 점

- 신살마다 원전·판본·현대 표의 차이를 조사하고, 선택한 규칙을 공개한다.
- 대운을 넓히려면 기준별 결과 비교, 절입 경계와 서머타임 표본 회귀, 출생시간 미상 시 가능한 시작 구간 표시를 추가한다.
- 연도별 해석은 사용자가 어떤 관계를 확인하는지 설명하고, 운명 단정이나 건강 진단으로 표현하지 않는다.
