# 한국 만세력의 계산 기준 비교

조사일: 2026-11-16. 검색으로 발견한 공개 설명 페이지 4곳을 편의 표본으로 골랐다. 이용자 수나 전문가 점유율을 반영한 표본이 아니며, 서비스의 실제 구현을 직접 검사한 것도 아니다. 표는 각 서비스의 공개 설명을 정리한 것이고 해당 서비스의 정확성을 보증하지 않는다. 같은 엔진이나 데이터를 사용하는지 확인되지 않았으므로 독립 표본으로 가정하지 않는다.

같은 ‘야자시’라는 이름이더라도 **일주 날짜와 시간의 천간을 각각 어느 일간으로 정하는지**까지 확인해야 한다. AevoStar와 잘될만세력은 0시 일주 변경의 시간 천간 처리에서 서로 다른 방식을 설명한다. 이름만 일치시킨 채 비교하면 결과가 달라질 수 있다.

## 잠정적인 제품 기준

위 편의 표본에서 기본값이 명확한 세 곳 중 두 곳은 23시 일주 변경을, 한 곳은 야자시 구분을 설명한다. 이는 시장 전체의 다수파가 아니다. 올바른사주도 23시 변경을 기본으로 설명하지만 선택 UI의 초기값은 직접 검증하지 않았다.

1차 구현의 **검토용 잠정 기본값**으로, 일주와 시주에 사용하는 시간 기준을 명시하고 23시 일주 변경을 고려한다. 동시에 자정 변경을 선택할 수 있게 하고, 자정 변경에서 시간 천간에 당일 일간을 쓰는지 다음 날 일간을 쓰는지 별도 설정으로 취급한다. 기본값 확정 전 더 넓고 독립적인 표본 및 문헌 근거를 확인한다.

출생지 경도 보정도 여러 서비스에서 쓰지만 균시차 포함 여부와 출생지 미상 시 처리 방식은 다르다. 기본 보정의 사용 여부는 아직 확정하지 않는다. 표준시, 경도만 적용한 평균태양시, 균시차까지 적용한 진태양시를 분리해 표시하고 각각의 시간대 처리를 검증한다.

## 역사적 서머타임에 관한 미해결 충돌

AevoStar는 1948년 서머타임 종료일에 대해 IANA 시간대 자료와 당시 포고 원문이 다르다고 설명한다. 이후 국사편찬위원회에 수록된 [포고와 9월 당대 기사](../검증/1948년_서머타임_사료충돌.md)를 확인한 결과, 9월 기사는 원래 예정된 22일보다 종료를 앞당겼다고 보도한다. 다만 기사가 적은 종료일과 한국천문연구원에 공개된 후대의 신문 조사 및 직접 확인한 IANA 원본도 하루 차이가 있어 실제 경계는 미확정이다.

## 다음 검증

- 추가로 표본을 선정하고 각 서비스의 기본 설정, 관련 옵션, 공유 엔진 여부와 확인일을 기록한다.
- 같은 생년월일시로 자시·시각 보정을 맞춘 결과를 비교한다. 서비스의 주장과 실제 출력을 구분한다.
- 한국천문연구원 역서와 시간대 이력의 원자료를 확보하고, 특히 1948년의 충돌을 조사한다.
- 결과가 다른 모든 설정을 사용자가 이해할 수 있는 말로 설명한다. 시간 미상 절입일에는 정오의 단일 결과가 아니라 가능한 후보를 제시한다.
