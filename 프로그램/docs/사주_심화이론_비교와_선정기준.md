# 사주 심화 이론: 비교와 선정 기준

작성일: 2026-11-16. 이 문서는 명리학의 전통 이론을 소프트웨어로 표현하기 위한 조사다. 자료에 등장하는 이론적 주장과 성격·미래 예측에 관한 주장은 실증적으로 확립된 사실로 취급하지 않는다. 아래 고전의 비교는 주로 공개된 학위논문 초록에 근거하며, 고전의 원문과 전체 논문을 정독해 검증한 완성 명세가 아니다.

## 1. 심화 해석은 무엇을 판단하는가

기초 계산은 사주 여덟 글자를 구하고, 일간을 기준으로 십성과 오행의 관계를 붙인다. 심화 이론은 그 관계들의 중요도와 구조를 해석한다. 이때 다음 질문이 서로 얽힌다.

1. 일간이 계절과 다른 글자의 영향을 받아 강한가 약한가? → 신강·신약, 왕쇠.
2. 월령과 십성 등을 기준으로 어떤 구조가 형성되는가? → 격국.
3. 특정 관점에서 무엇이 중요한 역할을 한다고 보는가? → 용신.
4. 계절의 춥고 더움, 건조와 습함을 어떻게 고려하는가? → 조후.
5. 대운이나 세운이 원국에 더해지면 관계를 어떻게 읽는가?

이 질문에는 하나의 보편적인 해답이 있다는 증거가 없다. 앞 단계의 판정이 달라지면 뒤 단계도 바뀔 수 있으므로 프로그램은 근거를 단계별로 남겨야 한다.

## 2. 용신 접근법의 비교

박재범의 비교 연구는 세 고전의 특징을 다음과 같이 구분한다. 이는 논문의 비교 틀이며 각 고전이 해당 방식 하나로만 구성된다는 뜻은 아니다. [1]

| 비교 관점 | 연구에서 연결한 고전 | 중심 질문 | 구현 시 필요한 것 |
|---|---|---|---|
| 억부 | 『적천수』 | 일간 등의 강약을 어떻게 조절하는가 | 강약 판정과 생조·극설의 우선순위 |
| 격국 | 『자평진전』 | 월령 등에서 파악한 구조가 무엇이며 무엇이 그 구조에 중요한가 | 격의 성립·변화·성패 조건과 용어 정의 |
| 조후 | 『궁통보감』 | 계절의 한난조습을 어떻게 살피는가 | 일간과 월령별 원문 규칙 및 예외 |

김승종의 연구 역시 세 문헌의 격국, 강쇠, 조후 관점을 비교한다. [2] 다른 연구는 격국과 용신의 관계 자체를 고전마다 다르게 다룬다고 지적한다. [3] 따라서 한 문헌에서 격국을 고르고 다른 문헌의 용신 규칙을 아무 설명 없이 섞으면 내부 기준이 모호해진다.

## 3. 신강·신약을 구현할 때

신강·신약은 일간의 강약을 설명하는 전통적 판정이다. 실제 사람이 강하거나 약하다는 뜻이 아니다. 일반적으로 조사할 항목은 다음과 같다.

- **월령**: 계절적 조건에서 일간의 오행을 어떻게 보는지.
- **통근**: 지지의 지장간에 일간을 돕는 뿌리가 있는지, 어떤 뿌리를 인정하는지.
- **생조와 극설**: 다른 글자가 일간을 생하거나 돕는지, 일간이 생하거나 극하는 대상 및 일간을 극하는 대상이 무엇인지.
- **상호작용과 예외**: 합·충 등으로 앞 판단이 변경되는지, 종격 등 특수한 구조를 별도로 볼지.

현재 조사만으로는 요소별 점수나 강약 경계가 통일돼 있다는 근거가 없다. 따라서 단순히 여덟 글자의 오행 개수를 더해 강약을 확정하거나, 임의 점수를 권위 있는 전통 규칙처럼 제시하지 않는다. 구현 전 선택한 문헌의 규칙과 예제를 확인한다.

## 4. 격국을 구현할 때

격국은 사주의 구조를 유형화하는 해석 방식이다. 백과사전은 격국과 용신을 정할 때 일간, 월주, 일지와 다른 기둥의 관계를 종합하는 예를 설명하고 다양한 격의 범주를 제시한다. [4]

구현을 위해서는 최소한 다음을 문헌별로 분리해야 한다.

1. 월지 및 지장간 가운데 무엇을 기준으로 격을 정하는가.
2. 천간에 나타난 글자(투간)가 판단에 어떤 영향을 주는가.
3. 후보가 여러 개일 때 우선순위는 무엇인가.
4. 격이 성립하거나 손상되는 조건은 무엇인가.
5. 정격과 특수격의 경계는 무엇인가.

이 다섯 가지가 확정되지 않은 상태에서 격의 이름만 붙이면 근거가 부족하다. 현재 문서는 항목의 지도이며 완전한 격국 계산표는 아니다.

## 5. 대운과 해석의 연결

대운은 일반적으로 10년 단위 흐름을 월주에서 진행시키는 체계다. 일부 구현은 연간의 음양과 성별을 사용해 방향을 정하고, 인접한 절입과 출생 사이의 간격을 시작 시점으로 환산한다. [5] 다만 이 구현이 현재 한국의 다수 방식이라는 빈도 자료는 확인하지 못했다. 성별 입력과 방향의 관계, 나이 환산·반올림, 만 나이와의 표시 차이를 구현 기준에 명시해야 한다.

대운 간지 계산과 대운 해석은 별도다. 계산이 결정되어도 원국과 만난 합·충, 용신에 대한 평가 등은 선택한 해석 이론에 따라 달라진다. 출생시간 미상 또는 절입 경계에서는 시작 시점도 불확실할 수 있다.

## 6. 다수 관례를 선택하기 위한 조사 방법

사용자 방침에 따라 널리 사용되는 한국의 관례를 우선하되, 현재 조사에는 실제 사용 비율을 추정할 표본이 없다. 다음과 같이 증거 수준을 구분한다.

| 구분 | 의미 | 현재의 취급 |
|---|---|---|
| 비교적 공통적인 계산 | 여러 문헌과 구현에서 같은 표나 순서를 제시 | 출처 확인 후 구현하고 공식 역법 자료와 비교 |
| 여러 선택지가 확인된 규칙 | 자시, 태양시, 격국·용신 등 | 각 선택지를 기록하고 사용 빈도 조사 전 잠정값으로 표시 |
| 특정 문헌의 해석 | 특정 책·주석이 제시하는 판단 | 해당 문헌의 규칙으로 이름 붙여 구현 |
| 검증되지 않은 자동 해석 | 규칙이나 근거가 확인되지 않은 문구 | 출력하지 않음 |

다수 관례 조사에는 독립된 한국의 만세력 서비스·명리학 교재·전문가 자료의 표본을 선정해 동일 질문을 비교한다. 서비스가 같은 라이브러리를 공유하면 독립 사례로 중복 집계하지 않는다. 표본의 선정 기준과 조사 날짜를 기록하고, 대표성이 부족하면 ‘여러 사례에서 확인’이라고만 표현한다.

## 7. 구현 순서

1. 한국 음양력과 네 기둥, 적용 기준과 출처 표시.
2. 오행, 십성, 지장간, 합·충의 **관계 식별**을 구현하고 근거를 보여 준다.
3. 신강·신약의 근거 자료와 평가 규칙을 선정하고 원문 및 예제로 시험한다.
4. 격국·용신은 문헌별 규칙으로 구분하고 판정 근거와 예외를 제시한다.
5. 대운·세운은 계산 기준을 명시한 뒤 원국과의 관계를 표시한다.
6. 길흉이나 인생의 단정적 판정보다는 전통적 해석의 맥락과 불확실성을 설명한다.
