# 십이운성 계산과 이론 차이

작성일 2026-11-16. 십이운성은 천간이 각 지지에 놓였을 때의 상태를 열두 단계로 구분하는 전통 명리 체계다. 인생의 생로병사에 비유하는 표현을 사용하지만 실제 사람의 수명이나 사건을 계산한 것은 아니다. [1]

## 단계의 순서

장생(長生) → 목욕(沐浴) → 관대(冠帶) → 건록(建祿, 임관) → 제왕(帝旺) → 쇠(衰) → 병(病) → 사(死) → 묘(墓) → 절(絶) → 태(胎) → 양(養) → 장생.

전통적인 비유로 탄생·성장·왕성·쇠퇴·새로운 시작을 표현한다. 어느 단계가 있더라도 사람의 생사나 건강에 대한 사실 판단으로 출력하지 않는다.

## 계산의 한 방식

아래는 [2]가 설명하는 **화토동궁, 양간 순행·음간 역행** 방식이다. 십간마다 장생이 시작하는 지지를 정하고, 양간은 지지 순서대로, 음간은 반대 순서로 열두 단계를 배치한다. [1]의 연구는 화토동궁이 현대 명리에서 지배적이라고 설명하지만, 사용 비율을 측정한 결과로 제시한 것은 아니다. 다른 학파와 견해가 있으므로 기본 설정을 확정하기 전에 검토한다.

| 일간 | 장생 지지 | 진행 |
|---|---|---|
| 갑 | 해 | 순행 |
| 을 | 오 | 역행 |
| 병 | 인 | 순행 |
| 정 | 유 | 역행 |
| 무 | 인 | 순행 |
| 기 | 유 | 역행 |
| 경 | 사 | 순행 |
| 신 | 자 | 역행 |
| 임 | 신 | 순행 |
| 계 | 묘 | 역행 |

예를 들어 갑 일간에서 해는 장생이고 다음 지지 자는 목욕이다. 을 일간에서 오는 장생이고 지지를 역행하므로 사는 목욕이다. 화토동궁이라는 말은 이 표에서 병·무, 정·기의 시작 지지가 각각 같다는 부분과 관련된다.

## 검증과 한계

[120조합 검증 코드](../검증/십이운성_120조합_대조.js)는 위의 시작점과 순역 계산을 `lunar-javascript` 1.7.8의 내부 배열과 비교했다. 10개 천간 × 12개 지지에서 불일치는 없었다. 동일한 이론을 구현한 두 자료가 일치한다는 것이며, 독립된 고전 대조나 모든 학파의 합의를 뜻하지 않는다.

프로그램에서는 십이운성의 계산 방식, 기준으로 삼은 천간, 비교 대상 지지의 위치를 함께 표시한다. 출생시각 미상이라 시지가 확정되지 않으면 해당 항목은 미상으로 남긴다.
